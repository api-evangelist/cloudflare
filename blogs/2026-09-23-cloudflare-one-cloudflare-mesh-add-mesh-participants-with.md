Cloudflare Mesh now makes it faster to add and manage participants from the dashboard. Select Add participant from Networking > Mesh to deploy a Mesh node or find the information needed to connect a client device . The updated dashboard includes the following improvements: More Mesh node deployment options — Install a node on Linux, Kubernetes, Docker Compose, or Docker CLI.
