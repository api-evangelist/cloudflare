Workers Metrics charts now show every release in the selected time range, including the full progression of gradual deployments . This makes it easier to correlate changes in memory, CPU time, errors, or latency with the code that was serving traffic. A gradual deployment appears as a single rollout across the chart, with shading that increases as more traffic moves to the new version.
