The Cloudflare API MCP server now serves Cloudflare skills ↗︎ through the Skills over MCP extension ↗︎ . MCP clients that support the extension discover the skills with skills/list and read their files at skill:// / . To use them, add https://mcp.cloudflare.com/mcp to an MCP client that supports the extension ↗︎ .
