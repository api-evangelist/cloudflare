MCP server portals can now connect to MCP servers available only on your private network. The portal uses Cloudflare Gateway to reach private hostnames and IP addresses without exposing the MCP server to the public Internet. Connect the server network to Cloudflare with Cloudflare Tunnel , Cloudflare Mesh , or another Cloudflare One connector .
