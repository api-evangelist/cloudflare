Audit Logs v2 now records view actions for supported endpoints, providing visibility into read activity across Cloudflare products. These actions correspond to GET requests and provide additional context for security investigations and forensic analysis. The Audit Logs v2 dashboard excludes view actions by default to reduce noise.
