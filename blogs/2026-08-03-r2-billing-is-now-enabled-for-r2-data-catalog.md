Billing is now enabled for R2 Data Catalog on non-enterprise accounts. R2 Data Catalog usage beyond the included free tier will appear on your next invoice. R2 Data Catalog charges based on two dimensions, in addition to standard R2 storage and operations : Catalog operations : $9.00 / million operations for metadata requests such as creating tables, reading table metadata, and updating table properties.
